# Produktion – Konzept-Vorschlag (14.10.2026, von Tom freigegeben – OHNE Wartung)

Ziel (Toms Absicht Finanzbildung): Eigenproduktion = **Fixkosten gegen Marge**. Lohnt erst ab Menge; Break-even sichtbar.

- **Rohstoffe** (am PC bestellen, Lieferung an R6, 1 Tag): Hülsen/Pappe, Oxidator, Metallpulver, Schwarzpulver.
  Sterne macht das Sternhaus selbst aus Chemie. Lager in Chemie-Boxen (begrenzte Menge je Box).
- **Rezept je Produkt:** Jedes Sortiment-Produkt der Klasse Rakete / Kugelbombe / Batterie kann selbst gebaut werden, sobald
  seine Straße steht. Rohstoffbedarf aus dem Satzgewicht (NEM) des Produkts abgeleitet – keine Handpflege je Produkt.
- **Kosten:** variable Kosten ≈ 45–60 % des Einkaufspreises; dazu fix: Werker-Lohn (1 je Straße + 1 Mischer), Strom, Abschreibung. Statistik zeigt Stückkosten bei aktueller Menge und Break-even-Menge.
- **Dauer:** Takt je Straße (Batterien schnell, Raketen mittel, Kugelbomben langsam + Trocknung = fertig am nächsten Spieltag).
  Fertigware geht automatisch ins Hochregal, von dort in Laden/Versand wie gekaufte Ware.
- **Qualität:** Werker-Erfahrung + Rohstoffqualität (Standard oder Premium, Premium teurer) → Ausschuss (2–15 %) und
  Effektqualität (wirkt auf Bewertung/Ruf). KEINE Wartung (Tom 14.10.: „ohne Wartung“).
  QS-Stichprobe täglich auf dem Testfeld (kurzer Effekt, sichtbar).
- **Was der Spieler tut:** Produktionsplan im Leitstand/Laptop (Produkt, Menge, Reihenfolge), Rohstoffe bestellen (Menge, Qualität),
  Werker einstellen, Störungen beheben (hingehen, Straße stoppen, Zelle freigeben).
- **Folgen falscher Entscheidungen:** zu viel produziert = Kapital im Hochregal gebunden + Lagerkosten; billige Rohstoffe =
  mehr Ausschuss und schlechtere Bewertungen; Rohstoffe ausgegangen = Straße steht, Werker kosten trotzdem.
